# CampusBoard 🎓

A modern, full-stack Academic Management Platform built with the MERN stack. CampusBoard centralizes university communication by providing a secure portal for faculty to broadcast announcements, schedule examinations, and share study materials, replacing fragmented messaging groups.

## ✨ Features

*   **Role-Based Access Control:** Secure JWT authentication with distinct privileges for 'Student' and 'Faculty' accounts.
*   **Live Notice Feed:** Real-time announcements featuring category tagging, pinning capabilities, and engagement tracking (Likes).
*   **Exam Calendar:** A chronological, easily scannable timeline of upcoming quizzes, midterms, and final assessments.
*   **Study Resources Library:** A centralized hub for faculty to distribute course materials, syllabus documents, and drive links.
*   **Platform Analytics:** Live dashboard metrics tracking total system engagement and identifying active publishers.
*   **Premium UI/UX:** Fully responsive, custom dark-theme interface utilizing modern glassmorphism design principles.

## 🛠️ Technology Stack

*   **Frontend:** React.js, React Router DOM, Custom CSS
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB, Mongoose ODM
*   **Authentication:** JSON Web Tokens (JWT), bcryptjs
